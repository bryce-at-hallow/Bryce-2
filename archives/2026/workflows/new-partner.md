# Workflow: Adding a New Partner

Use this workflow whenever a new parish is added to Bryce's book of business.

---

## Step 1: Gather Basic Info

Before creating the file, collect:
- Parish name
- City/area and state
- Diocese
- Partnership tier (Basic / Growth / Expansion)
- Partnership start and renewal dates
- Primary contact name, title, and email
- **Parish-wide premium discount code** (used by parishioners to access Hallow Premium)
- Any early notes on the relationship or onboarding status

---

## Step 2: Name the File

Follow the convention: `[parish-name]_[city].md`

- Lowercase, hyphenated

---

## Step 3: Fill Out the Template

Copy [`partners/_template.md`](../partners/_template.md) and fill in all known fields. Leave unknowns blank — don't guess.

Key fields to prioritize:
- Partnership tier and quality rating (PQR score)
- Parish-wide premium discount code
- Primary contact and communication preferences
- Any outstanding action items from onboarding

---

## Step 4: Set an Initial Quality Rating

Assign a PQR score (1–10) based on first impressions. See [`context/pqr-scoring.md`](../context/pqr-scoring.md) for the full rubric and action thresholds.

Update this score as the relationship develops.

---

## Step 5: Log the First Relationship Note

Add a dated entry under **Relationship History**:
```
- [Date] — Partnership started. [Brief description of first interaction, tone, any early signals.]
```

---

## Step 6: Update the Index *(future)*

Once a partner index file exists, add a one-line entry pointing to the new file.
