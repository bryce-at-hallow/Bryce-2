# Tools

The tools Bryce and the Hallow team use day-to-day. When suggesting how to capture, track, or communicate something, default to these tools.

---

## Notion
**Used for:** Documentation, internal knowledge base, meeting notes, partner resources

- Primary place for written documentation — SOPs, reference guides, team notes
- When summarizing a call or drafting notes for the team, format for Notion (headers, bullets, clean structure)
- Partner-facing resources (e.g., onboarding guides, feature overviews) may live here

---

## ClickUp
**Used for:** Task management, action item tracking, project follow-ups

- Where action items and follow-ups are tracked after partner calls
- When identifying next steps from a conversation, frame them as ClickUp tasks (assignee, due date, description)
- Bryce tracks his own to-dos and partner action items here

---

## Google Suite
**Used for:** Email, calendar, documents, and file storage

- **Gmail** — Primary channel for partner communications; all partner emails go through here
- **Google Calendar** — Scheduling partner calls, internal meetings, and follow-ups
- **Google Docs** — Collaborative drafts, one-pagers, and documents shared with partners or internally
- **Google Drive** — File storage for partner materials, assets, and shared resources. The **Hallow Partnership Resources** folder (root: `1kKhf3UTBqZIDcZVfaa4Pmm9rPGUXLPPh`) is the shared Drive sent to partners, containing guides, promotional assets, and documentation on the HALA partnership.

## Attention
**Used for:** Call recording, transcription, and AI-generated call summaries
**Link:** https://attention.com

- All partner calls are recorded and transcribed via Attention
- When prepping for or debriefing a call, Attention is the source for transcripts, summaries, and follow-up notes
- Claude has access to Attention via MCP — use it to pull recent call transcripts when relevant

---

## Notes for Claude

- When drafting action items, frame them for ClickUp (task title + description + due date if known)
- When drafting written summaries or internal notes, structure them for Notion
- When drafting partner-facing content, assume it will be sent via Gmail or shared as a Google Doc
- When a partner response calls for a resource file, check Google Drive before drafting — sending the right guide is often more valuable than a written explanation alone
