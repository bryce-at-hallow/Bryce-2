# Request Log

Tracks recurring request types to identify patterns and opportunities for new agents/skills.

**How to use:** After each conversation, Claude should add or increment the relevant request type. If a new pattern emerges that doesn't fit an existing category, add it.

---

## Request Types

| Request Type | Count | Notes / Examples |
|---|---|---|
| Draft follow-up email | 0 | Post-call, post-roadmap, re-engagement |
| Meeting prep / partner research | 0 | Background before calls |
| Post-call notes / summary | 0 | Capturing key points after a call |
| Partner profile update | 0 | Adding/editing partner info |
| Skill / agent creation | 0 | Building new Claude skills |
| Data pull / parish report | 0 | Pulling Omni data, generating CSVs |
| Communication drafting (non-email) | 0 | Talking points, Slack messages |
| Playbook / template creation | 0 | Standard response templates |
| Scheduling / calendar help | 0 | Finding times, scheduling calls |
| Other | 0 | Log specifics in Notes column |
