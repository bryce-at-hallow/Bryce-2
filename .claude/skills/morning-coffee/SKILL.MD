## Goal
Your Goal is to produce a morning report providing an overview of my day as well as a list of action items. Your Report should follow this format. 

## Format
1. Start with an H1 Opener with this title [Morning Coffee Overview (MM/DD/YYYY)]
2. A summary of today's action items from ClickUp
  - Pull Tasks that are assigned to me
  - Highlight on any tasks that are outstanding 
3. A summary of today's meetings 
4. Any new messages from my partners in my inbox. Prioritize partners with low PQR scores
5. Any new transacations from Ramp that need to be recorded. 
6. Tool Updates. A Summary of Messages from these distinctive labels. 
  - ClickUp
  - Hubspot
  - Ramp
  - Rippling
7. A Daily Agenda for Today

## Daily Agenda for Today 
- Pull all the tasks that I have scheduled for today or are due today or in the past
- Summarize all the tasks I have
- Come up with a daily agenda for today using time blocks on a calendar. Default to 30 minutes if there isn't a time 
 estimate. 
- Default to 15 minute increments (15, 30, 45, 60)
- The Table you produce should have these headers
  - Time Block 
  - Activity 
  - Source of Task (Hubspot, ClickUp, etc.)
